## 八、用户分层（窗口函数）

### 8.1 累计消费（按用户、按下单时间）

```sql
sum(pay_amount) over (partition by user_id order by order_timestamp
                      rows between unbounded preceding and current row)
```

示例（U000001，12 笔订单）：从首单 4,566.78 累计到 34,470.71，可直接用于 RFM 中的 M（金额）维度。

### 8.2 消费 Top5 用户

## 十、结论与建议

1. **业务整体平稳**：全年 GMV 波动 11%，无季节性，重点是提升而非稳定。
2. **履约是短板**：19.3% 的订单取消或退款，是最大的改善空间。
3. **会员体系失效**：四个等级客单价无差异，建议重新设计升级规则（按累计消费额）。
4. **渠道健康**：四渠道均分，无明显短板，可保持现有投入。
5. **高价值用户可挖掘**：Top5 用户贡献约 0.5% 的人头、2% 的 GMV，适合精细化运营。
